

# React – Web Development Coursework

This repository contains my React coursework for the Web Development course at Metropolia University of Applied Sciences.

The project is built using React and JavaScript, with assignments covering different React concepts and web development techniques.

## Topics Covered

- **React Components & Props** – Building reusable UI components.
- **Hooks & Custom Hooks** – Managing state and component behavior.
- **Context API** – Sharing user data and application state.
- **React Router** – Navigation between pages.
- **API Integration** – Fetching and managing data from an external API.
- **Authentication** – Login and logout functionality.
- **Likes & User Interactions** – Working with API data and user-specific actions.
- **Tailwind CSS** – Styling and responsive UI development.
- **File Uploads** – Handling media uploads.

## Technologies Used

- React
- JavaScript
- Vite
- React Router
- Tailwind CSS
- REST APIs
- Git & GitHub

## Repository Structure

The repository uses separate branches to organize coursework and track progress through different stages of the project.

Each branch represents a specific topic, assignment, or stage of development.
